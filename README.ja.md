# MatsPrefsUnifier

[English](README.md)

Unity Editor上で、lilToonマテリアルの選択した設定を一括コピーするためのツールです。

## コンセプト

MatsPrefsUnifierは、アバター制作におけるマテリアル設定の繰り返し作業を簡略化するために開発されました。

複数のマテリアルを使用するアバターでは、影・リムライト・距離フェードなどの設定をマテリアルごとに手動で調整する必要があり、時間がかかることがあります。

このツールでは、テンプレートとなるマテリアルを1つ指定し、必要な設定だけを複数の対象マテリアルに一括コピーできます。

## 概要

- **Unityバージョン：** 2022.3.22f1
- **メニュー：** `nur_ieren > MatsPrefsUnifier`

## 機能

- **複数の対象選択方法** — フォルダまたはGameObjectの階層を指定して、対象マテリアルを検索できます。
- **フォルダの再帰検索** — オプションでサブフォルダ内のマテリアルも検索対象に含められます。
- **GameObject階層検索** — MeshRendererおよびSkinnedMeshRendererに割り当てられたマテリアルを収集できます。非アクティブなオブジェクトを含めることも可能です。
- **lilToon系シェーダーへの対応** — lilToonマテリアルおよびUzumore Shaderを含む、対応する派生シェーダーを認識します。
- **影の設定** — 影に関連するシェーダープロパティをコピーします。
- **リムライトの設定** — リムライトに関連するシェーダープロパティをコピーします。
- **距離フェードの設定** — 距離フェードに関連するシェーダープロパティをコピーします。
- **キーワードの同期** — 関連するシェーダーキーワードを任意で同期できます。無関係なキーワードは維持されます。
- **プレビュー機能** — 設定を適用する前に、検索された対象マテリアルの一覧を確認できます。
- **進捗表示・キャンセル** — 一括処理中に進捗バーを表示し、処理をキャンセルできます。
- **詳細ログ** — 処理したマテリアルと実行結果をログに出力します。
- **Undoへの対応** — マテリアルの変更をUnityのUndoシステムに記録します。

## 使い方

1. `nur_ieren > MatsPrefsUnifier` を開きます。
2. フォルダ指定またはGameObject指定のいずれかを選択します。
3. 対象となるフォルダまたはGameObjectを指定します。
4. フォルダ指定の場合、サブフォルダも検索対象に含めるか選択します。
5. GameObject指定の場合、非アクティブなRendererも対象に含めるか選択します。
6. 対応するlilToon系シェーダーを使用したテンプレートマテリアルを指定します。
7. コピーする設定を選択します。
   - Shadow（影）
   - Rim（リムライト）
   - Distance Fade（距離フェード）
   - 関連するシェーダーキーワードのON/OFF
8. `プレビュー（対象マテリアルを確認）` をクリックし、処理対象のマテリアルを確認します。
9. `一括上書きを実行` をクリックし、確認画面で実行を確定します。

### 注意事項

- テンプレートマテリアルは設定のコピー元として使用され、一括処理の対象から除外されます。
- コピーされるのは、選択したカテゴリのシェーダープロパティのみです。
- 対象マテリアルに存在しないプロパティはスキップされます。
- キーワードの同期を有効にした場合でも、関連しないシェーダーキーワードは維持されます。
- GameObject指定では、MeshRendererおよびSkinnedMeshRendererに割り当てられたマテリアルのみが収集されます。
- 保存されていないマテリアルインスタンスは、GameObject指定による処理の対象から除外されます。
- 処理をキャンセルした場合、それ以降の処理は停止しますが、すでに更新されたマテリアルの変更は元に戻りません。
- 大規模な一括処理を実行する前に、プロジェクトのバックアップを取ることを推奨します。
