## Name
コピー元とコピー先のliltoon系マテリアルの設定を統合することから、  
"MatsPrefsUnifier"  
としました。

## Concept
アバターをインゲームで見た際に影などの当たり方を一致させる目的で作られました。  
反映させる前にどの設定を揃えるかをチェックマークでトグルできます。  

## Overview
Unity2022.3.22f1に導入してご利用ください。  

## Features
コピー元のマテリアルから影・リムシェード・距離フェードを一括コピーすることができます。  

## How to use
Unityメニュー > nur_ieren > MatsPrefsUnifierを押してタブを出してください。  
GameObjectかフォルダを指定した後、コピー元のマテリアルを指定し、反映させてください。  
統合したくない設定がある場合はチェックマークを外してから反映させてください。  
思ったとおりにならなかった場合はCtrl+Zで戻すことができます。
